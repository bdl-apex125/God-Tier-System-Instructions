# Prompt Sets Index

This folder groups related prompt files into named sets so consumers can quickly identify and apply the correct system instructions.

- **Core Features Set** — sets/SET_Core_Features.md (includes core runtime behavior). Adheres to `core-frameworks/PRINCIPLES.md`.
- **CO-STAR Framework Set** — sets/SET_CO-STAR.md (framework & usage). Adheres to `core-frameworks/PRINCIPLES.md`.
- **Protocol Set** — sets/SET_Protocol.md (workflow integration). Adheres to `core-frameworks/PRINCIPLES.md`.

Usage: open the set file and copy the referenced prompt into your AI Studio or system-prompt field.
